## 一、核心答案：什么是"三玄主"

"三玄"不是口号，而是 **三个正统仙道道统的创始人**，合称"三玄主"，是整部作品世界观的最远古锚点。

### 1. 三玄主是谁

| 道统 | 创始人 | 别号 | 师承 | 果位 | 关键遗产 |
|---|---|---|---|---|---|
| **青玄主** | **陆江仙** | 青玄子 | 师梁治子 | 至少仙君 / 修为至少仙君 | 青诣元心仪（仙器）；月华元府（始建后再由器灵玄谙接管）；初代青松观 |
| **兜玄主** | （无名氏） | 兜玄主 | 师梁治子 | 至少仙君 / 【真火】果位 | 传兜玄大道、太阴太阳金性、魏国皇族李氏祖先；阴司建制 |
| **通玄主** | （无名氏） | 通玄主 | 师梁治子 | 至少仙君 / 半妖血脉 | 传通玄大道、灵宝道统；妙繁天社稷宫、希阳观/不移观/落霞山四脉 |

### 2. 三玄主之上的"祖师爷"

- **梁治子**：三玄主之师，至少仙君。**"以天地作俎，阴阳为刀，将原始清炁划分为十二炁"**——这是整部作品"十二炁"修行体系的源头。
- **庄道人**：梁治子同辈，留下《太华经》，道真一派祖师。
- **魔主**：梁治子/庄道人同辈，徒武関，魔道四祖之祖。
- **祝昊**：梁治子/庄道人同辈，疑似人皇。
- **北世尊**：古释之师，**曾与梁治子相谈六日**（炁、龙、渡化、真魔、人间世、修立青冥），启发立下三十二天，是作品中"仙释合一"的文化起点。

> 💡 **核心结构**：**梁治子**（及道真一派）→ 三大弟子各立一道（青玄/兜玄/通玄）→ 三道之下分出三宗七门十二炁 + 无数世家 → 当下李氏家族。
> 这是一条完整的"道统树"。三玄主在最上面，下贯千年。

## 二、时代背景：从"天道混元"到"末法诸世"

整部作品的世界观经历了 **至少四个时代层叠**，越往下越接近当下李氏家族的主舞台。

### 时代 0：天道混元 / 上古仙治（梁治子时代）

- **梁治子**及同期仙人（庄道人、魔主、祝昊）尚在人间，**天道混元**。
- 道胎虽已为仙，**仍不算第一流**，因上有**玄主仙君**（青玄主、兜玄主、通玄主都是这个层级）。
- **三玄主** 存在于此一时期，他们是"道胎之上"的更古老者，被后人追封为"祖师"。
- **北世尊**立古释三十二天而后世尊崩，三十二天分崩离析化作六十九地，遂有金地。
- **第一次仙魔之争**：剑祖秦庚于此时斩杀**更木魔君、集木魔君**两位道胎。

### 时代 1：道统大定 / 玄主离世（青玄主 → 执渡真君 → 盈昃）

- **青玄主（陆江仙）** 收弟子东君、长泾玄君、秦庚等，分立恭华（青玄）、洞华、衍华三大道轨。
- **执渡真君**（修越果位金仙）继承第二代青松观后离世绝俗，往天外去。
- **盈昃**（道胎巅峰，太阳果位）继承第三代青松观，**重明六子**——**太越、太益、太祝、太昱、太栩、太青**——这六位金丹真君，分别是现代六大宗门（修越、金羽/青—蜀/长怀、衡祝、万昱、紫烟门、青池宗）的创派祖师。
- **蒯离**（少阳魔君）趁王元绶离世果位空悬，**越过希阳观**证少阳果位，与盈昃互相成全，被其**一分为三**（即"三分少阳"之由来：希阳观嫡传 + 观榭 + 某第三脉）。
- **觜玄魔祖**（至少仙君）折断真火，损伤天道，夺取众生寿，**开启了"兜玄万世之衰"**——这是一个时代转折点。

### 时代 2：兜玄末世 / 雷宫破灭 / 社稷之变（作品故事"开场前"二百年内）

- **王蕃**（兑金余位）得社稷相助，**助盛土覆雷**，雷宫破灭，王蕃自己**转世为张元禹**（当代最大操盘手）。
- **骆子朱（社仙）** 推翻雷宫另一仙道魁首之一，建立帝宣道宫，将通玄宫整合进其中，前往天外。
- **宁乡（素京/全丹果位）** 求道身死。
- **熊吾禁（稷仙）** 同为推翻雷宫之魁首。
- **天霞**（道胎巅峰，虹霞果位）以**二十四道霞光**镇压李乾元，**打断牝水娘娘突破道胎**，实力接近金仙。
- **东方甲鼎（日居）** 主导坎府之变，杀玄鼋夺【养命蛟】功绩；**蜮**共同作乱。
- **释道全面介入**：天觉（右世尊苏悉空）与天恕（左世尊释迦理）立今释道统，前往天外。
- **王元绶（少阳仙君）** 飞举紫榭宫离世——**少阳果位第一次空悬**，引发蒯离争夺。
- **桓暄（华央仙君）** 离世前往天外，【玄雷】果位去阙。
- **广陵（东戊仙君）** 前往天外，【戊土】果位留落霞山。
- **卫疑（观化真君）** 前往天外，【少阴】余位留不移观。
- **楼台无伤（朔楼真君）** 传承留给楼台愍，自身在世但三弟子之一的楼台愍最终身亡。
- **骆子朱** 整合通玄宫为帝宣道宫后离世，通玄宫从此不再是统一道统。
- **清昧仙君** 传下南乡四密（密汎、密樊、密彦、密林）。
- **北世尊**遗下的三十二天分崩离析 → 六十九地 → 金地独立。

> 这是整部作品"前史"中**最后一次大规模道统洗牌**。之后世界进入"诸道并立、群雄征伐"的当下。

### 时代 3：群雄征伐 / 碧落三千 / 当下李氏（卷一开场起）

- **大黎山脚、眉尺河畔的黎泾村**，李根水 → 李木田 → 李项平 / 李通崖 / 李长湖 / 李尺泾四兄弟开局。
- **陆江仙**（青玄主）残魂附着的青灰铜镜坠入河底，被李家三子**李项平**拾得。
- **陆江仙**命名为"玄鉴"，后世望月李氏的道统名号即源于此。
- **法宝与伏笔**：铜镜本体是仙器青诣元心仪的残片，与长庚仙君秦庚、寻阳池长庚青碑有关。陆江仙建立的家教叫"玄珠祀灵术"。

### 时代 4：当代 · 第一次南北大战（卷三~卷七）

- **李玄锋**（第十世）十八法师戮尽，油尽灯枯在望月湖坐化——第一次南北大战结束的标志。
- **李渊蛟**（第十一世）死于蜃镜洞天。
- **李曦明**（第十二世）成紫府，称"昭景"，望月李氏**第一位紫府**。
- **李周巍**（第十四世）"明煌真人"，紫府后期，**枢阳命数**，成为魏王——李家真正崛起的巅峰。
- **李绛迁**（第十五世）"昶离"，前世紫府后期【离火】，夺了哥哥李绛垄、李绛夏的命，性格狠毒但重视家族。
- **李绛淳**（第十五世）剑仙双修。

## 三、修行体系（境界完整表）

> **重要**：本作修行体系是**阴阳 + 五行 + 十二炁**复合体系，不是简单的"练气筑基"递进。下面是抽象化整理。

### 1. 主体四道（修行大路）

| 道 | 性质 | 代表 |
|---|---|---|
| **右道** | 以服气养性为代表 | 性命同修，神通养命，最正统元初的修行法 |
| **左道** | 紫金魔道 / 天胎魔道 | 三府合一肉体成为苦海之舟 |
| **外道** | 神丹 | 赐下引持、提拔眷属 |
| **内道** | 巫箓道 | 喝血食命，古老超服气养性 |

### 2. 紫府金丹道 / 紫金魔道（人族主流）

| 境界 | 关键节点 | 备注 |
|---|---|---|
| **胎息** | 凝聚六轮：玄景 → 承明 → 周行 → 青元 → 玉京 → 灵初 | 玉京轮显化神识；灵初轮接引天地灵气 |
| **练气** | 六轮圆满后采吞天地灵气 | 1-9 层；正法 vs 杂气 |
| **筑基** | 六轮兵解，流光凝仙基 | 初期/中期/后期/巅峰；可细分仙基品类 |
| **紫府** | 推举仙基、点亮巨阙、入升阳孕育神通 | 紫府境界最重"参紫仙槛"——能容纳更多神通的真人 |
| **金丹** | 煅出"金性"（不朽之意），证得果位 | 金性者寿千年；金性化为种种神物；"以己心代天心" |
| **道胎** | 突破条件之一是需要功绩 | 世间仙人之境 |
| **仙君 / 大罗 / 金仙** | 玄主仙君级 | 梁治子、庄道人、魔主、再往上 |
| **神丹 / 引持 / 代仙 / 结璘仙 / 郁仪仙** | 神君/道胎提拔的眷属位 | 古修认为"郁璘不假，引持非真" |

### 3. 释道体系（并行世界观）

| 境界 | 对应 | 备注 |
|---|---|---|
| **僧侣** | 胎息练气 | 钢筋铁骨 |
| **法师** | 筑基 | 古释正法等同筑基 |
| **怜愍** | 紫府前期 | 萨埵座 / 发慧座 / 金莲座 |
| **摩诃** | 紫府 | 一世至九世，**七世=紫府后期，八世=常见最高出手极限，九世=前往旃檀林** |
| **法相** | 金丹 | 不朽不灭 |
| **世尊** | 道胎 | 当世已无 |
| **方尊** | 仙君 | 世尊之上 |

### 4. 十二炁体系（青玄 / 兜玄金性核心）

按阴阳分 → 阴阳五行合一 → 衍化为十二炁。每个金性有自己的"性"（如太阴"胎息大臟玄牝性"）。

**阴**：太阴 / 厥阴 / 少阴
**阳**：太阳 / 明阳 / 少阳
**五行**：金（兑金、库金、庚金、齐金、逍金）/ 木（正木、角木、更木、集木、保木）/ 水（坎水、牝水、渌水、合水、府水）/ 火（离火、牡火、灴火、并火、真火）/ 土（艮土、宝土、宣土、归土、戊土、青宣）
**十二炁**：清炁 / 谪炁 / 寒炁 / 晞炁 / 紫炁 / 真炁 / 上仪 / 下仪 / 邃炁 / 华炁 / 煞炁 / 瑞炁
**天雷**：玄雷 / 霄雷 / 元雷
**并古法**：并鸺 / 上巫 / 玉真 / 全丹 / 衡祝 / 都卫 / 修越 / 身夔 / 司天 / 虹霞 / 长庚

> 每一性下又有"仙基"（筑基前所修），如太阴有"湖月秋"、"仪对影"、"结璘章"。

## 五、望月李氏家族史（核心骨架）

> 这是用户最关心的"三玄主 → 现在"的实地承接，每一世代有标志事件。

### 铜镜开局（卷一）

- **七世 李根水**：凡人，被元家毒死。
- **八世 李木田**：凡人，多虑善断、凶狠冷厉，为父报仇屠灭元家，分立嫡庶，购置田产。
- **九世**（四兄弟）：
  - **李长湖（伯）**：凡人，温顺恭谦，被元家余孽刺杀。
  - **李通崖（仲）**：筑基前期【浩瀚海】，"沉静谨慎似蛟蛇"，剑斩郁萧贵，**仙基崩碎而亡**。
  - **李项平（叔）**：灵初轮，"奸毒狠厉如饿狼"，**被山越筑基箓巫咒杀**。
  - **李尺泾（季）**：筑基前期【湖月秋】，剑仙，**被迟尉/参渌馥炼人丹**。

### 筑基建制（卷二-卷三）

- **十世（玄景）**：
  - **李玄宣（伯）**：练气九层，灰箓【持盈保泰】，谨言慎行，寿尽。
  - **李玄锋（叔）**：筑基巅峰【镂金石·天金胄】，**箭意拥有者**，第一次南北大战**戮尽十八法师**后油尽灯枯在望月湖坐化。
  - **李玄岭（仲）**：练气三层，死于法慧（净盏）。
  - **李景恬（叔）**：凡人，编撰族史。

### 紫府之始（卷三-卷五）

- **十一世（渊清）**：
  - **李渊修（伯）**：承明轮，"大方温和，渊思寂虑"，死于郁慕元/郁家江客卿。
  - **李渊蛟（季）**：筑基中期【泾龙王】，白箓【行气吞灵】，**谨慎多疑善谋能断**，**死于唐摄都**于蜃镜洞天。
  - **李清虹（仲）**：紫府灵修【霄雷】，师费望白，**明媚张扬但无情爱之心**。
  - **李渊平（伯）**：玉京轮，**掌权期间民丰物阜**，因早产血气虚弱寿尽早死。

- **十二世（曦月）**：
  - **李曦明（伯）**：紫府前期【明阳】，"昭景"道号，**望月李氏第一位紫府**，江南第一丹师。
  - **李曦治（季）**：筑基巅峰【长霞雾】。
  - **李曦峻（仲）**：筑基巅峰【松上雪】。

### 家族鼎盛（卷六-卷七当下）

- **十三世（承明）**：李承辽、李承㞧、李明宫、李承淮、李承晊、李承宰、李承暏、李承盘（羚跐）、李行寒之父。
- **十四世（周行）**：
  - **李周巍（仲）**：**紫府后期【明阳】**，"明煌真人"，**枢阳命数**，**青箓【明璋日月】**，魏王。
  - **李周洛（季）**：筑基前期【金兽羽】。
  - **李行寒（伯）**：筑基前期【道合真】，夫庄平野。
- **十五世（绛阙）**：
  - **李绛迁（仲）**：摩诃 / 宝牙金地之主，"昶离"道号，**前世紫府后期【离火】**，**夺了李绛垄、李绛夏的命**，性格狠毒但重视家族。
  - **李绛垄（仲）**：紫府前期【明阳】，**死于李绛迁**。
  - **李绛夏（仲）**：紫府前期【明阳】，**死于李绛迁**。
  - **李绛淳（季）**：筑基巅峰【香俱沉】，剑仙双修。
  - **李阙宛（伯）**：紫府前期【全丹】，青箓【明晦道弦】。

## 七、爽点模型（网文创作可借鉴）

> 抽象化总结，非抄原文。

### 1. 群像写法（核心）

- **每代主角，每个都不是终点**——李项平死在最早，但他是"开族初代"；李玄锋死于南北大战，但他是"筑基一柱"；李渊蛟死于蜃镜洞天，但他是"敛财暴君"；李周巍登顶紫府后期，但他已是体制内人。
- **家族 vs 个体**：个体再强也是为家族牺牲的"器"。这是《玄鉴仙族》最反高潮也最上头的爽点。

### 2. 三玄主作为"开局预设"

- 主角**看似凡人**，实则**站在远古仙人肩头**——这是"信息差 + 血统差"双重金手指。
- **不亲自下场**（"龟仙人"）反而是策略——避免被高阶发现，争取发育时间。
- **读者知道而剧中人不知道**——典型打破第四面墙。

### 3. 修真文明深度

- **境界分层 → 势力分层 → 家族分层**：每一层都有对应的修仙资源、传承、义务。
- **金性 / 果位 / 余位 / 闰位** —— 修仙界有"职位"和"编制"，**先来后到**决定一切。
- **阴阳十二炁**是世界观底层，**克制关系**扎实（火克金、金克木……）。

### 4. 历史架空感

- **夏→周→魏→齐→梁→赵/燕** 的朝代更替是骨架，**楚→宁→吴→越**的南朝是副线。
- **每一次国替**都伴随**道统消长**（魏灭→紫烟门倒向青玄、雷云寺入东海）。
- **借鉴《冰与火之歌》群像 + 《白鹿原》家族**——作者明确致敬。

### 5. 核心爽点模型

| 模型 | 表达 | 套用 |
|---|---|---|
| **「家族一荣俱荣」** | 一人筑基，全族跃升；一人战死，全族受创 | 家族流 |
| **「龟灵暗助」** | 主角看着像废物，实则暗中推动一切 | 苟道、藏拙 |
| **「世代接力」** | 父辈筑基，子辈紫府，孙辈开国 | 史诗流 |
| **「自有玄主」** | 是的，连我的铜镜都是远古仙君 | 血统论 |
| **「道统继承」** | 拜入青池宗/得到青松观认可/结发符 | 师徒流 |
| **「果位之争」** | 一名金丹真君之死，整个棋盘重排 | 阴谋流 |
| **「南北大战」** | 修真版的国战 | 战争流 |
| **「以弱胜强」** | 凡人族对抗紫府级阴谋 | 越级流 |

## 八、影响与价值

- **马伯庸** 评价："世代交替、前赴后继的史诗感"，"读者会眼睁睁看着一代代角色成长起来，然后承受着不同的痛苦乃至牺牲，只为让家族走得更远。"
- **当代严肃向仙侠的标杆**之一，与《诛仙》《凡人修仙传》不同的"群像家族史诗"路线。
- **冷峻笔调 + 权力更迭 + 人性挣扎**——这是季越人反复强调的"成人仙侠"标签。
