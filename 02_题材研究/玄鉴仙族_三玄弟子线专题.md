## ⚠️ 用户特别关注点

> "想知道三玄主代表弟子线" —— 包含四个层次：
> 1. **三玄分立**：梁治子立十二炁 → 三弟子各立一道 → 三道风格分野
> 2. **弟子分流**：每道之下的二代 / 三代 / 四代 / 五代代表人物
> 3. **当下格局**：三道繁衍至今形成的"三宗七门十二炁 + 数十世家"地图
> 4. **因果链**：弟子线的"果位继承 / 师徒分裂 / 跨界出走"如何撬动时代转折

## 一、总论：三道分立 → 弟子分流 → 当下格局

### 1. 三个锚点：梁治子 → 三玄主 → 当下

整部《玄鉴仙族》的世界史是一棵**道统树**：

```
梁治子（至少仙君 / 划分十二炁 / 正始两仪）
├── 庄道人（同辈 / 《太华经》/ 道真一派祖师）
├── 魔主（同辈 / 魔道之祖）
├── 祝昊（同辈 / 疑人皇）
└── 北世尊（同辈 / 古释之师）

↓ 三弟子各立一道

├── 青玄主 陆江仙（青玄子 / 至少仙君 / 月华元府 / 青诣元心仪）
├── 兜玄主（无名 / 至少仙君 / 【真火】果位）
└── 通玄主（无名 / 至少仙君 / 半妖血脉 / 灵宝道统）

↓ 二三四代弟子下传，繁衍三宗七门十二炁 + 无数世家
```

### 2. 三道风格分野（不是简单平行的三个派别）

| 道统 | 风格关键词 | 核心金性 | 核心因果 | 当代代表 |
|---|---|---|---|---|
| **青玄** | "太阳 / 太阴 / 阳之极轨" | 太阳、明阳、修越、衡祝、渌水、府水、紫炁 | 恭华、洞华、衍华三道轨轮替；**执渡** 创衍华 → 盈昃回归恭华 | 修越宗、青池宗、衡祝道、紫烟门、大鸺葵观 |
| **兜玄** | "真火 / 阴之母 / 雷法 / 丹器之极" | 真火、玄雷、坎水、牝水、都卫、司天、离火 | 雷宫覆灭 / 平明津之战 / 觜玄之乱 | 宛陵宗、东离宗、雷云寺、堰羊寺宫、阴司 |
| **通玄** | "少阳 / 灵宝 / 圜中" | 少阳、少阴、厥阴、戊土、宝土 | 三分少阳 / 妙繁天之变 / 社稷之变 / 落霞之危 | 希阳观、不移观、观榭、落霞山、堰羊寺宫 |

### 3. 当下格局一句话总结

- **青玄**当下最强但被"重明六子 / 三宗七门"分摊；**盈昃死后**（一分为六）留下真空，导致**张元禹**得以【兑金】为主角搅局；
- **兜玄**当下**雷宫已覆**（被盛土+王蕃+骆子朱+熊吾禁联手推翻），**堰羊寺宫**（释道融合）和**阴司**（兜玄期清道统）成为兜玄在当下的两根支柱；
- **通玄**当下**通玄宫已散**（被落霞山利用社仙一道暗算），但四嫡传脉（希阳观/不移观/观榭/落霞山）仍各自存续，且**观榭**的【少阳】是三家中最值钱的"果位空悬"。

## 二、青玄道统·代表弟子线

### 1. 第一代：陆江仙（青玄子）

- **果位**：至少仙君；青玄主。
- **师承**：梁治子（同门庄道人、魔主、祝昊）。
- **关键遗产**：
  - 仙器 **青诣元心仪**（后碎成多片，月华元府建于一碎片之上）。
  - **月华元府**（始建于青玄期，由器灵玄谙接管延续至今）。
  - **初代青松观**（后由执渡重建为第二代、盈昃重建为第三代）。
- **历史定位**：青玄道的**唯一官方祖师**。传说"曾持全部太阴太阳"（疑似），后身谢太阴，残魂附铜镜，坠入大黎山眉尺河。
- **当下意义**：**铜镜（玄鉴）落入李家** 是整部作品的"开局预设"；陆江仙的青玄道统在明面已散，但暗线通过 **李氏** + **月华元府** + **青松观** 三线维系。

### 2. 第二代：东君 / 虞转 / 长泾玄君 / 秦庚 / 执渡 / 盈昃 等

陆江仙（青玄子）弟子众多，**第二代金仙/仙君密度极高** —— 这是青玄道统在道统期的最高峰。

| 弟子 | 果位 / 修为 | 道轨 | 关键遗产 / 结局 |
|---|---|---|---|
| **东君**（玄神元真紫耀仙君 / 日宫太阳真君 / 四君一体） | 【太阳】果位 | 太阳轨 | **击杀天狼**（道胎）；青玄太阳一脉的开创者 |
| **虞转**（长塘玄君） | 仙君 / 【太阴】果位 | 洞华道轨 | 传世道统常郡韩氏、九邱一脉；散去道统封闭洞华天后前往天外 |
| **长泾玄君** | 仙君 | 恭华道轨 | 传道统予**盈昃**；是恭华一脉的"传灯者" |
| **秦庚**（长庚仙君） | 空证【长庚】果位 | 剑仙 | **世间第一位剑仙**，论攻杀能追三玄主；于寻阳池留**长庚青碑**；疑似为追杀觜玄前往天外 |
| **执渡真君**（通明行衍修越真君 / 清静二仪玄君） | **金仙 / 【修越】果位** | 出身洞华，自立**衍华道轨** | 以执阴渡阳成道；**重建第二代青松观**；离世绝俗，往天外 |
| **盈昃**（道胎巅峰） | 【太阳】果位 / 【太阴】余位 | 恭华道轨 | 长泾玄君所传；**重建第三代青松观**；成道前修习观华显要秘境，居于恭华天；**重明六子之师**；与蒯离互相成全；疑似突破金仙失败身死 |
| **玄泱真君** | 至少道胎 / 【玉真】果位 / 【长庚】余位 | 剑仙 | **世间第二位剑仙**；前往天外 |
| **陆赥魔君** | 至少道胎 / 魔道四祖之一 | 魔遗 | 师青玄子；点化渟世；已死；魔遗"玄赥魔遗" |

**因果链**：

```
陆江仙（青玄子）
├── 东君 → 击杀天狼 → 太阳一脉立轨
├── 虞转（长塘玄君） → 洞华道轨 → 封闭后传常郡韩氏 / 九邱
├── 长泾玄君 → 恭华道轨 → 传盈昃
├── 秦庚（长庚仙君） → 剑祖 → 长庚青碑 → 追杀觜玄
├── 执渡真君 → 自立衍华道轨 → 第二代青松观 → 张元禹承其遗
├── 玄泱真君 → 第二位剑仙 → 命阳白玉剑落入月华元府
├── 陆赥魔君 → 魔道四祖之一 → 渟世
└── （若干其他弟子）
```

盈昃是"第三代青松观主"，其**嫡传弟子**即**重明六子**——这是整部作品"三宗七门"的总源头：

### 4. 执渡一系（衍华道轨）：从太青门下分出的"对手玩家"

- **执渡真君** 第二代青松观主，创"衍华道轨"，**离世绝俗往天外**。
- **张元禹**（前世**王蕃**）以青玄 **"衍华上青"** 名义入 **海内三金** 之第三位（逍金 / 程圜 / 张元禹），形成"青玄内部对手戏"。
- **海内三金完整排序**：逍金（观解逍金）→ 兑金（程圜·太钧执锋）→ 兑金（张元禹·衍华上青）。"余而走闰，闰而为主"是张元禹的核心玩法（详见《张元禹阴谋专题》）。

### 5. 虞转一系（洞华道轨）：九邱山的秘密传承

- **虞转（长塘玄君）**封闭洞华天后，把道统传给了**常郡韩氏**（兜/青双修）。
- **韩辙**（清悬/垣下真君 / 微月璘统太阴玄君）→ 金丹巅峰 / 【太阴】征璘余位 / 兜玄主二弟子 / 高平郡王 / 39岁修道119岁金丹 / 建立**兜玄太垣庭** / 突破道胎失败身死。
- **虞紊道**（金丹【少阴】）→ 曾跟随楼台无伤修行，经王元绶指点建立**九邱一脉**。
- **太洮**（金丹【府水】）→ 师盈涤 → 建立**九邱山**（已死）。

## 三、兜玄道统·代表弟子线

### 1. 第一代：兜玄主（无名）

- **果位**：至少仙君 / 【真火】果位。
- **师承**：梁治子。
- **关键遗产**：
  - 传**兜玄大道**（含太阴太阳金性、丹器之极）。
  - 建制**阴司**（兜玄期清道统的仙道版"地府"）。
  - 传**魏国皇族李氏**祖先（与祝昊+共顼共同造魏）。
- **历史定位**：兜玄道的**唯一官方祖师**；魏国皇族李氏兜玄血脉的源头。

### 2. 第二代：共顼 / 桓暄 / 淳于昭 / 清昧

兜玄主弟子是整部作品"中古史"的核心推动者——他们奠定了**魏、齐、梁、宋**四国的道统格局。

| 弟子 | 道号 / 别号 | 果位 / 修为 | 关键遗产 / 结局 |
|---|---|---|---|
| **共顼** | 少顼 / 共卑玄土司命玄君 | 仙君 / 【都卫】果位 / 曾为【戊土】金丹 / **人皇** | 子**胉栎**；杀**枢阳**（道胎【明阳】）；死后两肋与麟皮交给胉栎，治理栎地无能让民怨沸腾，孕**二子一麟一蝉**，**后裔立国为魏** |
| **桓暄** | 清权 / 华央仙君 | 【太阳】闰位 → 【玄雷】果位 | 师兜玄主；**立轨北宫玄雷法道**（兜玄第一脉嫡传）；前往天外 |
| **淳于昭** | 清乙仙君 | 【司天】果位 / 师兜玄主 | 本姓**姜**（为避尊者讳改姓淳于）；记名弟子**参堰子**；立轨**天衍**；舍身求道前将司天位别吾道司天门改为**大衍天玄箓** |
| **清昧仙君** | （无名） | 【真火】余位 | 师兜玄主；**兜玄丹器之极**；建立**滁仪天**；传世道统**南乡四密**（密汎、密樊、密彦、密林） |
| **参堰子** | 大至禅天参堰 / 中世尊 | 方尊 / 至少道胎【青宣】 | **淳于昭记名弟子**；建立**堰羊寺宫**；七相祖师；尝试仙释合一失败失了心智化作堰山 |
| **武関魔君** | （无名） | 至少道胎 / 【清炁】闰位 / 兄北世尊 / 师魔主 | 魔道四祖之一；魔遗"武関遗产"；**提出废去五德学说改立清邃六轮论** |
| **夜侯** | （无名） | 疑似【上巫】果位 / 至少道胎 | **建立阴司**；前往天外但未完全离世 |

**因果链**：

```
兜玄主（【真火】果位）
├── 共顼（人皇 / 【都卫】）→ 杀枢阳 → 胉栎 → 立魏
├── 桓暄（华央仙君 / 【玄雷】） → 北宫玄雷法道（嫡传第一脉）
├── 淳于昭（清乙仙君 / 【司天】） → 天衍道轨 → 堰羊寺宫（释道融合）
├── 清昧仙君（【真火】余位） → 滁仪天 → 南乡四密
├── 参堰子（方尊 / 【青宣】） → 堰羊寺宫 → 七相祖师
├── 武関魔君 → 魔道四祖之一 → 清邃六轮论
└── 夜侯 → 阴司 → 兜玄期清道统
```

### 3. 第三代：桓暄一系（北宫玄雷法道 / 雷宫）

- **桓暄**（华央仙君 / 【玄雷】果位）前往天外后，**【玄雷】果位去阙**，由弟子继承。
- **雷宫尊者**（金丹【玄雷】）：雷宫坐镇者，**死于王蕃 / 素京**。
- **听鸣尊者**（徐方听鸣天霆尊者 / 金丹【玄雷】听鸣余位）：雷宫幸存者之一，**梁灭后被张元禹 / 东方未明杀害于雷云洞天**。
- **照广真炁玄闳神君**（【真炁】果位 / 道真一派）：**死于雷宫覆灭**。
- **堰羊寺宫首徒**：雷宫破灭后入东海重建秩序，建立**雷云寺**（兜玄 → 释道融合实验）。
- **摩都**（金丹【玄雷】）：**南乡道统第一道子**；听鸣死后**携摩通畟宫飞升**。

### 4. 第三代：淳于昭一系（天衍道轨 / 堰羊寺宫 / 释道融合）

## 七、「三分少阳」专题

### 1. 事件起因

- **王元绶**（少阳仙君 / 【少阳】果位）**飞举紫榭宫离世**。
- **【少阳】果位第一次空悬**，引发通玄道统内部争夺。
- **蒯离**（少阳魔君 / 师长夙魔君）趁机**越过希阳观**证少阳果位 —— 这是一个**魔道弟子侵夺正道果位**的标志性事件。

### 2. 关键转折：与盈昃互相成全

- 蒯离证道 → 与**盈昃**（道胎巅峰 / 【太阳】果位 / 第三代青松观）互相成全。
- **盈昃**疑似**突破金仙失败身死** → 留下 **重明六子** 与**观榭蒯离** 两条线。
- **蒯离被盈昃一分为三**，但**并未陨落**。

### 3. 三分结果

| 三分之一 | 持有人 / 名称 | 身份 / 道统 | 备注 |
|---|---|---|---|
| **希阳观** | **屈笪**（少笪 / 道胎 / 【少阳】余位） | 王元绶嫡传 / 通玄嫡传第一脉 | 玄下五仙之一 |
| **观榭** | **蒯离**（少阳魔君 / 榭卿真君 / 【少阳】果位） | 通玄嫡传第三脉 | 蒯离身被一分为三但本体未陨 |
| **西晏魔 / 真君**（西永衷胜白晏真君） | 象雄国 / 胜白殿 | **通玄嫡传第三脉海外支** | 金丹 / 【少阳】余位 / 与落霞山不和 / 恶怨惊人 |
| **东方未晞**（晞阳龙君 / 【晞炁】闰位） | 螭属 / 真螭第四子 | **三分少阳之一**（继承谶言"未晞"） | 金丹 |

### 4. 因果链

```
王元绶（少阳仙君）飞举紫榭宫 → 【少阳】果位空悬
        ↓
蒯离（魔君 / 师长夙）越过希阳观证少阳
        ↓
与盈昃互相成全（青玄-通玄跨道统配合）
        ↓
盈昃疑似突破金仙失败身死（但留下重明六子）
        ↓
蒯离被一分为三 → 希阳观 / 观榭 / 西晏魔（海外）
        ↓
三分之中：东方未晞、钟离白鹿后来也持有【少阳】余位
        ↓
三分少阳 → 当下三股力量：
        ├── 希阳观：屈笪→屈铅（紫府巅峰）→玄下五仙
        ├── 观榭：蒯离本体（通玄嫡传第三脉）
        └── 北溟殿/胜白殿：钟离白鹿 / 西晏魔
```

### 5. 三分少阳的战略意义

> 【合理推演】**三分少阳不是"分裂"，而是"降维"**：
>
> 1. **蒯离证少阳** 已经是"魔道侵正道"的僭越行为，对通玄道统构成合法性危机。
> 2. **盈昃将其一分为三**：一方面保留蒯离证道的【少阳】果位（避免天道崩坏），另一方面**稀释**了蒯离对果位的独占权，把【少阳】余位散落人间。
> 3. **西晏魔 / 东方未晞 / 钟离白鹿**各自持有【少阳】余位 —— 这是"通玄嫡传第四脉（落霞山）"也必须**跨派系合作**才能凑齐少阳道统的完整拼图。
> 4. **战略后果**：
>    - 通玄嫡传第三脉（观榭）成为**"三分少阳"持有者**，在通玄内部享有**果位空悬红利**（少阳金性稀缺，谁持有谁就是通玄的话事人之一）；
>    - 但**蒯离身未陨**，保留了"魔道侵夺"的法理依据 —— 这是作品当下**通玄道统不稳定的根源**。
>    - 与**重明六子分摊恭华太阳一脉**（盈昃死后太阳果位分散）是**同样的设计逻辑**：避免单一果位独占、避免任何一道尾大不掉。

## 九、三道之间的人才流动

### 1. 青玄对魔道的清洗（秦庚斩更木 / 集木）

> **事件**：第一次仙魔之争（"天道混元"时代早期）。
> **执行者**：**秦庚**（长庚仙君 / 空证【长庚】果位 / **世间第一位剑仙**）。
> **目标**：**更木魔君**（道胎【更木】果位）+ **集木魔君**（道胎【集木】闰位→【集木】果位）。
> **结果**：秦庚斩杀更木、集木二魔君。集木魔君是**先杀死【集木】果位持有人，再登上果位** —— 这是一个"以魔道侵夺正道果位"的典型案例。

> **因果链**：
>
> ```
> 更木 / 集木魔君（魔道四祖体系）
> ↓ 觊觎正道【更木】果位 / 【集木】果位
> ↓ 先杀原果位持有人，再登上果位（"集木模式"）
> 秦庚（青玄 / 世间第一位剑仙）
> ↓ 论攻杀能追三玄主
> ↓ 第一次仙魔之争中斩杀二人
> 魔道暂时收缩（直到觜玄 / 长夙等魔道四祖出世）
> ```

### 2. 通玄道的内战（长夙魔君 → 蒯离 → 三分少阳）

> **事件**：蒯离（魔道四祖之一**长夙魔君**之徒）证少阳。
> **逻辑**：蒯离本是魔道弟子（师长夙），却要**越过希阳观**（正道王元绶嫡传）**证少阳果位** —— 这是**魔道弟子对通玄道的反向侵蚀**。
> **结果**：蒯离与盈昃（青玄第三代青松观主）互相成全，被一分为三 —— **青玄介入通玄内部事务** 的典型案例。

### 3. 兜玄道的"东西对峙"（堰羊寺宫 vs 昭元仙府）

> **堰羊寺宫**（淳于昭记名弟子参堰子所创）是**释道融合的道场**。
> **昭元仙府**（李乾元为府主）是**兜玄丹道的代表**。
> 二者同属兜玄体系，但风格不同：堰羊寺宫偏释道（仙释合一），昭元仙府偏丹道（李乾元被天霞以二十四道霞光镇压九幽）。
> **因果**：堰羊寺宫首徒**雷宫破灭后入东海重建秩序，建立雷云寺** —— 这是**兜玄道统的"释道救火队"**。

### 4. 兜玄-通玄合作（盛土+王蕃+骆子朱+熊吾禁推翻雷宫）

> **事件**：雷宫破灭。
> **参与者**：
> - **盛土**（外援 / 王蕃所借之力）
> - **王蕃**（前世张元禹 / 通玄【兑金】余位 / 后期转青玄）
> - **骆子朱**（社仙 / 至少道胎【宣土】果位 / 通玄→社稷 / 建立帝宣道宫）
> - **熊吾禁**（稷仙 / 【归土】果位 / 通玄→社稷）
> - **宁乡 / 素京**（兜玄金书道 / 【全丹】果位 / 王蕃妹夫）
>
> **结果**：
> - **雷宫尊者身死**；
> - **听鸣尊者幸存**（后被张元禹 / 东方未明杀害于雷云洞天）；
> - **骆子朱**借势整合**通玄宫**为**帝宣道宫**，前往天外；
> - **王蕃**自己**死亡 → 转世为张元禹**。

> **关键**：这是**通玄内部 + 兜玄内部 + 通玄-兜玄之间** 三方合作的典型案例 —— **通玄王蕃+兜玄素京+通玄社仙+通玄稷仙** 联手推翻了**兜玄雷宫**。

### 5. 兜玄-释道合作（堰羊寺宫的"七相祖师"）

> **参堰子**（淳于昭记名弟子 / 方尊 / 【青宣】果位）建立**堰羊寺宫**，七相祖师，传天下释土之法。
> **大至禅天参堰** —— 这是作品**唯一**"仙道高修同时为释道方尊"的人物。
> **结果**：堰羊寺宫首徒**雷宫破灭后入东海重建秩序，建立雷云寺** —— 这是**兜玄→释道→雷云寺** 的三级跳。

### 6. 青玄-兜玄跨道统配合（盈昃 × 蒯离）

> **盈昃**（青玄 / 道胎巅峰 / 【太阳】果位）+ **蒯离**（通玄魔道 / 道胎 / 【少阳】果位）
> → 互相成全 → **三分少阳**
> 这是**青玄话事人介入通玄内部事务**的典型案例。

### 7. 通玄-通玄内战（天霞 vs 阳瞝）

> **天霞**（道胎巅峰 / 【戊土】闰位→【虹霞】果位 / 落霞山）
> **vs**
> **阳瞝**（金丹 / 东穆天 / 落霞山内部反对派）
>
> **结果**：**阳瞝**曾与**摩都**联手**围杀太祝真君**差点让衡祝道当场陨落；**真璀玄君**（前世梁堂）是**戊光道统中主张阴阳平衡的金丹**，支持**闻清昼求金（紫炁果）** —— 落霞山内部实际上是**阴阳平衡派 vs 夺明阳派** 的路线之争。

## 十、爽点模型抽象（道统继承 / 师徒流）

### 1. 道统继承 / 师徒流的爽点内核

| 模型 | 抽象结构 | 套用提示 |
|---|---|---|
| **「师徒链」** | 祖师 → 二代 → 三代 → 四代 → ... → 当下主角 | 每代人有自己的"果位继承 + 道统分裂" |
| **「道统树」** | 一棵多叉树（梁治子 → 三玄主 → 当下七门/数十世家） | 主角可选择任意一根树枝攀爬 |
| **「果位继承」** | 师父的果位死了 → 徒弟补位 → 徒弟的徒弟抢位 → 三家分果位（三分少阳） | "少阳"是当下最值钱的空缺 |
| **「师徒流」** | 拜师 → 接受道统 → 守道 → 叛道 / 守道 / 开道 | 三种结局，每一种都是爽点 |
| **「道统毁灭」** | 雷宫破灭 / 通玄宫散 / 青松观被张元禹算计 | 道统毁而不灭 → 转入地下 → 复仇者 |
| **「跨道统配合」** | 盈昃+蒯离 / 王蕃+素京+骆子朱 | 反派 / 盟友 / 师徒身份交织 |
| **「果位悬空红利」** | 【少阳】三分 → 谁持有谁就是话事人 | 观榭、西晏魔、东方未晞、钟离白鹿 |
| **「道统分裂」** | 重明六子 / 三分少阳 / 通玄宫被帝宣道宫整合 | 每一次分裂都制造"小宗师独立成宗"的爽点 |
| **「祖师显灵」** | 陆江仙附铜镜 / 玄谙重塑性格线 | 主角看似凡人，实则站在远古仙人肩头 |
| **「道统树自带 BOSS」** | 三玄主 + 二代 + 三代 + ... + 释道方尊 / 世尊 | 越靠近根部，BOSS 越古老、越不可战胜 |

### 2. 主角视角的"师徒流爽点"

> **假如主角是李氏**（参考百度百科"望月李氏"词条）：
>
> - **第一代师父**：陆江仙（青玄主 / 残魂）→ 铜镜认主（"看似捡破烂实则捡仙器"）。
> - **第二代师父**：青池宗司元白（筑基前期）→ 七弟子李尺泾（筑基前期【湖月秋】/ 剑仙）。
> - **第三代师父**：青池宗萧元思（筑基后期【朱丹参】/ 丹师）→ 徒李曦明（紫府前期【明阳】）。
> - **第四代师父**：青池宗崔决吟（紫府前期【明阳】）→ 徒李绛梁（紫府前期【离火】）。
> - **第五代师父**：乔文鎏（三疑真人 / 紫府中期【少阴】）→ 徒李绛淳（筑基巅峰【香俱沉】/ 剑仙）。
> - **第六代师父**：李周巍自任魏王（紫府后期【明阳】/ 枢阳命数）→ 自创李氏家族道统。
>
> **每一代主角拜入一个师父的门下**，**每一代师父都比上一代更强**，**每一代主角都比上一代更能打** —— 这是**纵向的师徒升级**。

### 3. 反派视角的"道统继承爽点"

> **假如主角是张元禹**（前世王蕃）：
>
> - **前世**（王蕃 / 通玄【兑金】余位）→ 助盛土覆雷 → 转世；
> - **今世**（张元禹 / 青玄【兑金】/ 金丹前期 / 主动压制修为）→ 主导两次庚兑之变 → 害死至少 4 位金丹 → 极有可能是下一位道胎；
> - **化身**（善青道人 / 神通巅峰【兑金】/ 国师）→ 在齐国当操盘手。
>
> **每一代反派都把"道统继承"玩成"果位 + 道统 + 化身"的三层套娃** —— 这是**反向的师徒流**（师父是反派，徒弟也是反派，但反派自己当主角）。

### 4. 跨作品借鉴的"道统继承"骨架

> 如果要写一部《道统继承流》的群像仙侠：

> 1. **设定一个"祖师 + 三弟子" 的初始分裂**（参考梁治子 + 三玄主）。
