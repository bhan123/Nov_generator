## 一、总论：阴司作为「地下修仙政府」的位置

### 1.1 一个道胎级道统

百度百科 innerText 明确把阴司列入「仙人道统」条：

> ▪ **阴司（兜）**
> 　兜玄期清道统

这意味着阴司 **不是 "金丹道统"（如宛陵宗/东离宗/南火天府）**，而是 **与堰羊寺宫、青松观、观榭、落霞山、北宫玄雷法道、蓬莱并列的"仙人级"道统**。
内文进一步给阴司的标签：

- **建道者**：夜侯（道胎，疑似【上巫】果位）—— 建立阴司，**前往天外但未完全离世**；
- **现存者**：「阴司主人」—— **道胎**，**疑似状态不好或者离世**（这是全书对"地下政府首领是否还在岗"最暧昧的标注）；
- **行政班子**：杨金新（杨判）/ 汤戍（汤判）/ 江判 三位 **幽阴司判**（皆【谪炁】果位），以及若干"阴差"（张贵、王隆）。

> **抽象判断**【合理推演】：阴司的组织形态 = **道胎 / 道主 + 判官体系 + 阴差体系 + 枉死鬼服役者**。
> 这是一个 "**道胎挂名、判官运行、阴差执法、枉死鬼劳役**" 的四层架构，本质是 **"道统 + 政府" 二合一**。
> 与其说阴司是 "修仙版阎罗殿"，不如说它是 "**修仙版「都察院 + 大理寺 + 司礼监」混合体**"，但主人是仙人。

### 1.2 「兜玄期清」的关键定性

innerText 给阴司的派别标记只有四个字：「**兜玄期清道统**」。

- 「**兜玄**」派—— 与 **兜玄主** 同谱系。兜玄主是「至少仙君，【真火】果位，师梁治子」，是阴司的远祖级靠山；
- 「**期清**」—— 字面像 "**期清之炁**"（十二炁中清炁、谪炁皆属"清系列"），意味着阴司所修道炁属 **【谪炁】** 系——而杨金新/汤戍/江判的果位正是【谪炁】。

> **因果链**【合理推演】：
> 阴司道胎（夜侯/阴司主人）→ 持有【上巫】果位 + 出身兜玄大道 → 在地表下建立以【谪炁】为核心的修仙政府 → 用 "判官 / 阴差 / 枉死鬼" 的行政分层，把 **"对地表修士的秩序监管"** 制度化。

### 1.3 与 "地表仙府" 的对比

| 维度 | 地表仙府（如昭元仙府/月华元府） | 阴司 |
|---|---|---|
| 等级 | 金丹 → 神丹 → 紫府果位级 | 道胎级（含主人可能离世的现实） |
| 行政 | 府主/三司/门徒 | 判官/阴差/枉死鬼 |
| 任务 | 道统延续 + 修真传承 | 修真秩序监管 + 死亡登记 + 跨界调停 |
| 入口 | 地表洞天 | 地下（或 "**幽阴所**"，对应章节标题 "大璺阴所" / "大璺在身"） |

**关键章节信号**：
- 第六百八十五章「**阴司登名**」—— 说明阴司有 **"登名簿"** 制度（地表修士一旦"被登名"等于上了仙府 / 阴司的备案）；
- 第一千零八十七章「**大璺阴所**」+ 第一千零九十七章「**大璺在身**」—— 「**大璺**」+「**阴所**」是阴司地表分支的口径。

## 二、阴司位置与势力范围（与落霞山/南海摩通/宛陵宗的地理关系）

### 2.1 三个"地表节点"—— 阴司的触手

阴司不是孤立地下王国，它通过 **三个地表节点** 与地上修仙界相互渗透：

```
【阴司总部（地下·道胎）】
        │
        ├─→ 节点 A：落霞山（地表监督·兜玄通玄交叉区）
        │
        ├─→ 节点 B：南海摩通畟宫（南海修真秩序·兜→通）
        │
        └─→ 节点 C：宛陵宗（越国大宁上宗·兜玄天衍道轨）
```

### 2.2 节点 A：落霞山

**落霞山**（innerText「仙人道统 ▪ 落霞山（通）」条）是 **通玄大道戊光道轨**（嫡传第四脉），祖师为 **广陵（东戊仙君）**—— 持有【戊土】果位、通玄主四弟子、戊光落霞祖师、**前往天外**。

落霞山的核心班底：

| 果位 | 人物 | 角色 |
|---|---|---|
| 【戊土】果位 | **广陵（东戊仙君）** | 通玄主四弟子，戊光落霞祖师，**前往天外** |
| 【戊土】闰位 → 【虹霞】果位 | **天霞** | **道胎巅峰**，借【戊土】空证【虹霞】，道行接近金仙，意在夺取【明阳】天光意兆 |
| 【戊土】余位 | 落霞山某位 **金丹** | 余位继承者 |
| 疑似【晞炁】闰位 / 法器凫晞束麟索 | **姚臣蔺** | 疑似金丹 |
| 【虹霞】 | **薛殃** | 紫府巅峰 |
| 天楼道轨仪衡冲然道统，天素加持 | **姚贯夷（平彰真人）** | 紫府巅峰 |
| 【离火】 | **魏阚** | 紫府巅峰，求金失败身死 |
| （未列果位） | **谯成襄** | 紫府巅峰，求金失败身死 |

> **关键现象**：innerText 在「张元禹」条目下明确写出 —— **"面对落霞阴司主动退让保持金丹前期修为"**。
> 这是一条把 **"落霞山" 与 "阴司"** 写在一起的关键句。
> **抽象判断**【合理推演】：
> - 落霞山 = 阴司的 **地表眼睛**（天霞道胎 + 广陵仙君遗泽 + 至少一位金丹级余位）。
> - **"落霞阴司" 是修仙界默认的合并称谓**，意味着 **阴司把落霞山视为其在通玄大道上的代表机构**。
> - 所以张元禹不是怕阴司总部的道胎，而是怕 **"落霞山的道胎级存在 + 阴司制度"** —— 这个组合能让他金丹前期的化身无处遁形。

### 2.3 节点 B：南海摩通畟宫

**摩通畟宫**（innerText「金丹道统」条）：

> ▪ 摩通畟宫（**兜→通**）
> 　原兜玄大道南乡密林道轨，雷宫破灭后显世入南海重建秩序，脱离兜玄后自号摩通道统。

关键人物：**摩都**（金丹【玄雷】，南乡道统第一道子）—— "听鸣死后携摩通畟宫飞升"。

**因果链**：

1. 雷宫破灭（原兜玄大道列阳道统核心道场）→ **社稷之变中落霞山利用社仙一道暗算**（骆子朱/社仙），导致通玄宫/帝宣道宫倒塌；
2. 雷宫破灭后，**堰羊寺宫首徒入东海建立雷云寺**（策雷泊云法道）；
3. 与此同时，**原兜玄南乡密林道轨 显世入南海重建秩序 → 改号摩通畟宫**；
4. 听鸣尊者（金丹【玄雷】听鸣余位）在梁灭后被张元禹/东方未明杀害于雷云洞天 → **摩都携摩通畟宫飞升**。

> **抽象判断**【合理推演】：
> - 雷宫 → 雷云寺（东海）和摩通畟宫（南海）是 **"兜玄雷法一脉" 在地上的两个分支**；
> - 摩通畟宫（南海）**由兜玄脱钩自号通玄** —— 这跟阴司的"兜玄期清"是 **同一政治走向**：老兜玄体系分崩后，地方机构纷纷 **借仙君级阴司** 自我赋权。
> - 因此南海摩通畟宫对阴司 **存在天然的制度性依赖**（地表最远、机构最新、必须靠阴司对海上龙族进行秩序协调）。

### 2.4 节点 C：宛陵宗（越国大宁上宗）

**宛陵宗**（innerText「金丹道统 ▪ 宛陵宗（兜）」条）：

> ▪ 宛陵宗（兜）
> 　兜玄大道天衍道轨丹络南乡之道宛陵道统

关键设置：
- **重沅真君**：金丹【少阴】，以陵阳不易宫（法宝）将大衍天玄箓/大衍天素书（**司天位别**）镇压在宛陵天；
- **林衡江（淮洚剑仙）**：紫府巅峰【少阴】，师盛玉，姑怜玑，意灵门，封闭宛陵天后灭门自刎，宛陵天开启后复活；
- **盛玉真人**：紫府巅峰【玉真】，徒林衡江，意灵门，死于蒋清；
- **司马椴**：宛陵天不去峰，已死；
- **怜玑仙子**：夫蒋清，侄林衡江。

> **抽象判断**【合理推演】：
> - 宛陵宗 = **越国大宁的国教级存在**（"魏灭后诸修南下，……仙教为宛陵上宗"）；
> - 大宁国是阴司在江南的政治延伸 —— **萧祠"在阴司的帮助下从楚国篡夺江南建立吴国"** 就是这层关系的最好注脚。
> - 所以阴司不是抽象的 "地下秩序"，而是 **"江南（吴）+ 越国大宁（宛陵）"** 两国建国的幕后赋能者。

## 三、阴司修体系（与玄主道统的关系 / 阴神是「独立修仙路径」）

### 3.1 三种 "阴司相关" 修为身份

innerText 明确给出 **三种** 阴司体系的"修为身份"，且它们都不在紫府金丹道 / 紫金魔道 / 异府同炉道 / 服气养性道 / 巫箓道 / 释道 之中：

| 身份 | 果位 / 性质 | 代表人物 |
|---|---|---|
| **幽阴司判** | 【谪炁】 | 杨金新（杨判）/ 汤戍（汤判）/ 江判 |
| **阴神** | 【谪炁】 | 杨功曹（子杨锐仪，女杨宵儿，求金失败转为阴神） |
| **阴差** | 未列果位（推定为 【谪炁】余位或 12 轮基础修行） | 张贵、王隆 |

另列 "**现阴司枉死鬼**"（详见 §七）—— 这是 "**死后继续在阴司服役**" 的特殊身份，崔颚就是代表。

### 3.2 阴司修真 vs. 玄主道统

**判断**【合理推演】：阴司修体系 **不是 "独立修仙路径"，而是 "行政修仙路径"** ——

- 它 **依附于兜玄大道 + 谪炁果位体系**，本质上是 **"把修仙界的果位当作官位来分配"**；
- 一个人可以 **先正常修行（紫府/金丹）→ 求金失败 → 转为阴神**（典型：杨功曹"求金失败转为阴神"）；
- 也可以 **一开始就在阴司体系内升迁**（如张贵、王隆，从阴差做起）。

> 这意味着 "阴司修" 是 **"表里双轨"**：
> - **表**：紫府金丹道/天胎魔道/服气养性道 的正常修行；
> - **里**：谪炁果位 + 判官/阴神/阴差的官职修行。
> - **交汇点**：果位 —— "**谪炁**" 是阴司修真谱系的 "母果位"，与兜玄大道同根。

### 3.3 阴神 vs. 结璘仙 vs. 神丹

百度百科明确区分了 "神丹 / 引持 / 代仙 / 结璘仙 / 郁仪仙" 的修为含义：

> 通常乃是神君一类的人物所传，用以提拔眷属，追随修行，哪怕是道胎，能够提拔的人物亦不多。
> 赐下引持对金丹道胎来说是个负担，可结璘郁仪并不会对太阴太阳的道胎增添麻烦，甚至结璘郁仪仙在修为上仍然属于自己修成的。
> 神丹之士在古修体系中，是明确和结璘郁仪分开的，古修认为【郁璘不假，引持非真】。

而 **"阴神"** 在 innerText 中只出现一次 —— 杨功曹 "求金失败转为阴神"。

> **抽象判断**【合理推演】：
> - **阴神** 是 **"求金失败 + 转入阴司"** 的一种退而求其次的修仙路径；
> - 它 **既不是结璘仙（结璘章·太阴/太阳附属），也不是郁仪仙（太阳附属），也不是神丹（引持类）**；
> - 它是 **"谪炁行政化"** 的人格载体 —— 持有人的金性散失但仍有神识，转入阴司任判官/阴差/地祇。
> - **章节目录信号**：第一千二百八十四章「**阴神**」+ 第一千二百八十五章「**布韬**」—— 阴神体系在卷十二（征淮入洛）有专门展开。

### 3.4 阴司 "阴阳两层还是同一谱系" 之争

**结论**：**同一谱系，但分两层**。

```
┌───────────────────────────────────────────────────────┐
│                  阴司修真谱系（单谱系）                   │
├───────────────────────────────────────────────────────┤
│ 【上层】道胎级：阴司主人 / 夜侯 / 阴司主人 → 持有【上巫】果位│
│ 【中层】果位级：幽阴司判 / 阴神 → 持有【谪炁】果位        │
│ 【下层】行政级：阴差 / 枉死鬼 → 谪炁余位 / 阴司冥职       │
└───────────────────────────────────────────────────────┘
```

> **关键依据**：
> - 内文把阴司归在 "兜玄期清道统" —— 单谱系；
> - 但其行政分层（道胎 / 判官 / 阴差 / 枉死鬼）呈现明显 "**仙人 / 官员 / 衙役 / 苦役**" 的四层形态；
> - 这种分层 + 单一谱系 = **阴司 = 道胎挂名的修仙政府**，**不是 "独立于玄主道统之外" 的另一套宇宙观**。

## 四、阴司监管职能（监管落霞山/南海/魏国/梁国/金地/南海之上的"修真秩序"）

### 4.1 监管对象清单

阴司在地表的活动被 innerText 零散记录，可抽象为 **6 类监管**：

| 监管对象 | 监管方式 | 证据 |
|---|---|---|
| **越国 / 大宁 / 吴国** | 协助凡俗政权更替 | "萧祠：……在阴司的帮助下从楚国篡夺江南建立吴国" |
| **魏国明阳金性持有者** | 把紫府/神丹【明阳】修士"登记在册" | "崔颚：……现阴司枉死鬼"（详见 §七） |
