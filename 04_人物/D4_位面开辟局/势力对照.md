# 位面开辟局 — 势力对照表

> 本书势力架构基于 **SHI-005（上庭治统·跨界官僚制）+ SHI-006（位面开辟局·主角机构）** 两张新卡，
> 配 **ZY-011 世界品级榜** 做经济底座、**FB-004 待勘小世界** 做舞台生成器。
> 与 D1（七层地图+八大古族）、D3（天骄阁+凡尘派）完全零重叠。

---

## 一、三层权力结构

```
┌─────────────────────────────────────────────────────────┐
│ 治统天（上庭）                                            │
│   三大总阁：天机阁（发现界壁）│开辟阁（管分包）│监察阁（查账）│
│   铁律：上界之人不得真身降临小世界                          │
└───────────────────────┬─────────────────────────────────┘
                        │ 只下敕封、抽成、评级
┌───────────────────────▼─────────────────────────────────┐
│ 诸天会盟（中界）                                          │
│   位面开辟局（总局 + 第七分局 ← 主角所在）                  │
│   清界卫 │ 跨界商帮（万货行等）│ 各大跨界宗门                 │
└───────────────────────┬─────────────────────────────────┘
                        │ 派勘界吏入界、立约、分地
┌───────────────────────▼─────────────────────────────────┐
│ 小世界（待勘 / 已勘 / 待回炉）                             │
│   本地宗门 · 凡人王朝 · 界灵                               │
└─────────────────────────────────────────────────────────┘
```

**这套结构的功能**：把"修真界的一切冲突"翻译成"行政层级之间的利益分配"。
主角之所以能活，是因为铁律（上界不能下来）；主角之所以能赢，是因为他掌握了"翻译权"。

## 二、上庭治统（SHI-005）

| 机构 | 职能 | 与主角关系 | 关键词 |
|---|---|---|---|
| **天机阁** | 感应界壁波动，发布"发现公告" | 一切的起点；决定哪个世界"值得勘" | 谁发现了世界，谁就有优先权 |
| **开辟阁** | 制定开辟五步、下发分包、收抽成 | 主角的最终甲方 | 分包、验收、抽成率 |
| **监察阁** | 查账、受理越级上访 | 卷六主角的"最后通道" | 制衡、对账、质询会 |
| **清界卫** | 执行、镇压、灭口 | 沈屠出身；卷六主要武力对手 | 界壁封锁、跨界追杀 |

**上庭的三条潜规则**（全书反复出现）：

1. **"账要好看"** —— 世界真实状况不重要，报表漂亮最重要
2. **"自然衰亡"** —— 所有被抽干的世界，一律记为自然衰亡，从此无人追责
3. **"不问过程"** —— 只要抽成足额、验收通过，怎么弄的没人管

> 💡 写作要点：上庭**不写成一个邪恶组织**。每个执事都敬业、都有 KPI、都相信自己在"维护秩序"。恶来自制度，不来自人。

## 三、位面开辟局（SHI-006）

### 3.1 四类编制

| 编制 | 职能 | 地位 | 代表人物 |
|---|---|---|---|
| **勘界吏** | 入界勘定、写《勘定书》 | 最低，从九品起步，靠出勤熬资历 | 陆见微、老勘 |
| **文书** | 管理卷宗、走流程、管人事 | 中游，最有政治前途 | 苏拂 |
| **清界卫** | 武力执法、界壁封锁 | 特殊，独立于文官系统 | 沈屠 |
| **承包商** | 编外，自负盈亏，去开辟 | 名义最低，实际自由度最高 | 卷一卷末之后的陆见微 |

> **制度设计的狠处**：承包商制度是"体制的垃圾桶"——脏活、险活、背锅活都扔给编外，成功了功劳归分局，失败了责任归个人。但**这也是唯一能自己做主的位置**。

### 3.2 开辟五步（全书流程骨架）

| 步 | 执行方 | 产出文件 | 主角能插手的地方 |
|---|---|---|---|
| 1 发现 | 天机阁 | 《发现公告》 | 无 |
| 2 勘定 | 开辟局勘界吏 | **《勘定书》** | ★ 主角的核心战场：数据写多少、怎么写 |
| 3 立约 | 承包商 + 本地势力 | **《开辟之约》** | ★ 约期、分成、义务条款 |
| 4 分地 | 分局 + 承包商 | **《分地册》** | ★ 谁算首功、地怎么切 |
| 5 册封 | 上庭 | **《界主印》** | 只能申请，不能决定（卷七要废的就是这一步） |
| 6 评级 | 开辟阁+监察阁 | 《评级书》 | ★ 品级升降，直接决定抽成 |

### 3.3 第七分局内部（官场戏主场）

| 层级 | 人物 | 立场 |
|---|---|---|
| 五品主事 | **裴无咎** | 求稳、求报表好看；压主角最狠 |
| 六品副使 | 周敬之（配角） | 摇摆，谁强跟谁 |
| 从六品文书 | **苏拂** | 主角的镜像，走通体制 |
| 从九品勘界吏 | **陆见微** | 主角 |
| 从九品勘界吏 | 老勘（已贬守库房） | 主角师父 |
| 编外承包商 | 卷末的陆见微 | 主角第二身份 |

## 四、世界品级对照（ZY-011）

| 品级 | 灵气上限 | 派驻上限 | 上庭抽成 | 世界寿命 | 现实类比 |
|---|---|---|---|---|---|
| 一品 | 极高 | 化神 | 30% | 万年 | 直辖特区 |
| 二品 | 很高 | 化神 | 35% | 七千年 | 一线 |
| 三品 | 高 | 元婴 | 40% | 五千年 | 强二线 |
| 四品 | 较高 | 元婴 | 45% | 三千年 | 二线 |
| 五品 | 中 | 金丹 | 55% | 两千年 | 三线（主流战场） |
| 六品 | 中下 | 金丹 | 60% | 一千五百年 | 四线 |
| 七品 | 低 | 筑基 | 70% | 八百年 | 五线（鸡肋） |
| 八品 | 很低 | 筑基 | 78% | 五百年 | 六线 |

**写作用法**：每次提到一个世界，必须报"几品、抽成几成、还剩多少年"。读者会自己算这笔生意值不值。

## 七、势力关系演变（7 卷）

```
卷一：分局（压迫者）→ 主角（被贬）
卷二：分局（冷眼）→ 主角（承包商，开始有地）
卷三：分局（抢功）→ 主角（升六品，进圈）
卷四：上庭（嘉奖）→ 主角（执行者，变坏）
卷五：上庭（试探）→ 主角（签字，留一手）
卷六：上庭（通缉）→ 主角（叛局者）
卷七：上庭（对账）→ 主角（废制者）
```

**核心规律**：主角与体制的关系是"**靠近 → 进入 → 认同 → 反噬 → 重订**"，不是"被压迫 → 打回去"。
他必须先成为体制的既得利益者，他的反叛才有分量。

## 八、与 D1/D3 势力卡的不重叠验证

| 项目 | D1（SHI-001+004） | D3（SHI-002+003） | **D4（SHI-005+006）** |
|---|---|---|---|
| 势力主体 | 古族 / 名门 | 天骄阁 / 凡尘派 | **上庭 / 开辟局** |
| 冲突性质 | 血脉与家族 | 血统论与真相 | **抽成率与账目** |
| 反派形态 | 魂族（恶） | 天骄阁（垄断） | **制度（无恶人）** |
| 升级方式 | 打穿七层地图 | 揭穿真相 | **升品级、进编制** |
| 主角身份 | 弃子→族裔 | 弃徒→真相持有者 | **公务员→承包商→叛局者** |

**结论**：D4 的势力架构是"行政层级"而非"地理层级"，与前三本无概念重叠。
